Lesson 33 — Bootstrap Cover Example

This lesson demonstrates Bootstrap’s Cover Template — a simple fullscreen layout perfect for landing pages, hero sections, and minimal home screens.

Learn more

Cover template for Bootstrap by @mdo.

Teaching Notes

1. Fullscreen Background Technique:
We use background-size: cover; to ensure the coral reef image fills the entire viewport without distortion. The fixed keyword keeps the background stationary while content scrolls, creating a subtle parallax effect.

2. Dark Overlay for Readability:
Bright images can make text unreadable. The body::before pseudo-element adds a semi-transparent black overlay (rgba(0,0,0,0.45)) across the entire screen. This improves contrast without hiding the background.

3. Centering Content with Flexbox:
The Cover Template uses display: flex; on the body to vertically and horizontally center the hero text. This is cleaner and more responsive than older margin-based techniques.

4. Max-Width for Readability:
The .cover-container is limited to max-width: 42em;. This prevents long line lengths, which improves readability and keeps the hero text visually balanced.

5. Transparent “Glass” Teaching Notes Block:
The notes use rgba(255,255,255,0.25) plus backdrop-filter: blur(6px) to create a modern glassmorphism effect. This allows the coral reef background to show through while keeping the text readable.

6. Why This Layout Works Well for Landing Pages:
The Cover Template is intentionally minimal. It focuses the user’s attention on a single message or call to action. The fullscreen background sets the mood, while the centered text delivers the core idea.

7. Real-World Use Cases:
• App landing pages
• Portfolio intros
• Product announcements
• “Coming Soon” pages
• Hero sections for marketing sites

8. Accessibility Considerations:
• Ensure text contrast remains high enough over the background.
• Avoid overly busy images behind important text.
• Keep interactive elements clearly visible and easy to tap.

9. Customization Ideas:
• Add a gradient overlay instead of a solid one.
• Animate the background using CSS transitions.
• Add a subtle drop shadow to the hero text.
• Swap the background image based on time of day.
