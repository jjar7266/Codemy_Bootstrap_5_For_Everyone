# Codemy.com — Bootstrap 5 For Everyone (Modernized Edition)
### Projects and exercises completed while following John Elder’s Bootstrap course

This repository contains all of my work from the Codemy.com **Bootstrap 4 For Everyone** course,
**updated and modernized to Bootstrap 5** for current best practices.

Each lesson is recreated step‑by‑step with clean code, organized examples, and clear explanations
to reinforce the concepts taught throughout the course — while replacing outdated Bootstrap 4
components with their modern Bootstrap 5 equivalents.

## What’s Inside
- Lesson‑by‑lesson HTML examples
- Modern Bootstrap 5 implementations of the instructor’s Bootstrap 4 code
- Extra examples expanding on the material
- Teaching notes and summary blocks for future reference
- A consistent, easy‑to‑navigate project structure

## Topics Covered
- Bootstrap installation via CDN
- Typography, images, and tables
- Navbars, buttons, alerts, badges, breadcrumbs
- Cards, carousels, dropdowns, modals, list groups
- Forms and input groups
- Jumbotrons (modern Bootstrap 5 hero sections)
- Popovers, tooltips, progress bars
- Containers and the grid system
- Borders, colors, shadows, text utilities
- Example themes and customization
- Album, cover, and carousel examples

## Purpose
This repo serves as a personal learning archive and a reference for revisiting the concepts taught
in this course. All code is written by **Jose “Joe” Ruiz**, following the Codemy.com curriculum
while improving clarity, structure, and readability — and updating everything to modern standards.
