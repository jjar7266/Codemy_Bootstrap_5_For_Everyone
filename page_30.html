Lesson 30 — Text Align

Basic Alignment

.text-start — This text is aligned to the start (left) on all screen sizes.

.text-center — This text is centered on all screen sizes.

.text-end — This text is aligned to the end (right) on all screen sizes.

Responsive Alignment

.text-sm-end — End aligned on SM (≥576px) and larger.

.text-md-end — End aligned on MD (≥768px) and larger.

.text-lg-end — End aligned on LG (≥992px) and larger.

.text-xl-end — End aligned on XL (≥1200px) and larger.

.text-xxl-end — End aligned on XXL (≥1400px) and larger.

Font Weight & Style Utilities

.fw-bold — Bold text.

.fw-bolder — Bolder text (relative to the parent element).

.fw-semibold — Semibold text.

.fw-medium — Medium weight text.

.fw-normal — Normal weight text.

.fw-light — Light weight text.

.fw-lighter — Lighter text (relative to the parent element).

.fst-italic — Italic text.

.fst-normal — Normal (non-italic) text.

Teaching Notes

Text Alignment: Use .text-start, .text-center, and .text-end for basic alignment. Responsive versions follow the pattern: .text-{breakpoint}-{alignment}.

Font Weights: Bootstrap 5 includes a full set of weight utilities such as .fw-bold, .fw-light, .fw-semibold, and more.

Font Styles: Use .fst-italic for italics and .fst-normal to reset back to normal.
