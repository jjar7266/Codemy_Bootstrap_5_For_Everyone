Teaching Notes

Replacing SVGs: The original Album example uses SVG placeholders. We replaced them with real images using the <img> tag and Bootstrap’s .card-img-top class.

Scaling Images: Because our images are different sizes, we used object-fit: cover; and a fixed height to keep the cards uniform.

Same Folder Images: Since the images are in the same folder as this HTML file, the correct path is simply: src="filename.png".

Real-World Use: This is exactly how developers customize Bootstrap templates for real projects.
